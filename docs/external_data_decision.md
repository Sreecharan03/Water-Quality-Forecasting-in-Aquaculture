- AquaSustain-Bench is not used as evidence about real ponds, not even as a test set.

- Earlier statements in this project calling it the "best candidate" were based on the Zenodo description and are corrected here.
- Also corrected: the Mendeley "AquaSense" dataset (fhnb2h7hyc), which the first search summary mislabelled as a Colombia tilapia dataset, is simulated ("computer-generated data, and not real-world sensor measurements") and is rejected for the same reason.

## Limits to state wherever this dataset is used
- Tidal salt marsh in a temperate region, not a managed fish pond: no stocking, feeding or aeration.
- Most salt-marsh temperatures (down to -1.8 °C; 5th percentile 3.9 °C) lie far below the 21 to 31 °C the Eluru models were trained on, so an Eluru-trained model would see inputs far outside its training range. That makes zero-shot transfer a **stress test of domain shift**, not a fair accuracy test.
- The `depth` column holds values of 0.00 to 0.10 m (sampling depth), so it carries no tide information.
- At least 5% of the converted oxygen values are about 0 mg/L (the 5th percentile prints as 0.00), which may be real night-time anoxia in shallow marsh ponds or a sensor artefact. The zero question from Phase 2 therefore recurs and must be handled by a written rule, not silently.
- Dissolved oxygen is converted from umol/kg with an approximate density; absolute mg/L may be off by a small percentage.

## Recommended use (needs your approval)
1. **Method replication (primary).** Run our frozen pipeline (cleaning rules, causal features, split design, honest baselines, anchored LightGBM, conformal ranges, low-oxygen alert, same success rules) on this dataset with its own split (13 months allows a proper chronological split and held-out ponds). This answers: *does the method work on a second, independent, real dataset?*
2. **Zero-shot model transfer (descriptive).** Apply the Eluru-trained models unchanged and report the failure modes (range shift, pH shift). No tuning, no claim of accuracy.
3. Keep the request to the Fish Welfare Initiative open: it is still the only route to an aquaculture-pond external test in the same format.
